# Pizza-Sales-Insights

This project analyzes pizza sales data using SQL to uncover key business insights. It examines sales performance, customer ordering patterns, and product popularity to inform better operational and strategic decisions.
By querying total revenue, order trends, top-selling products, and sales by category and size, the project demonstrates SQL’s power for data exploration and business analysis. These insights help optimize menu offerings, tailor marketing strategies, and improve inventory management to reduce waste and boost customer engagement.
